本项目测试手头上的stm8s103fp6的各种功能，不采用官方的库文件，采用sdcc编译，stm8flash烧录，没有任何第三方依赖，尽量采用面向对象的方式来构造引脚设备；

本项目采用压电陶瓷蜂鸣器接入PD4测试beep；
PD5和PD6做为uart的txd/rxd接入计算机的串行（或USB-TTL），波特率115200，8N1
Led使用开发板的测试led，PB5接入；
按键接在PA3，为单引脚设备，没有采用矩阵，有三类的处理事件，单击、双击和长按，矩阵模式可以支持更多的按键，暂时没有这个需求，三个按键事件通过uart打印并采用三种不同的声调通过beep响应；
PC4接10k电位器中间抽头测试AD转换；
启动时通过EEPROM测试写入上电次数。

功能均在本地测试通过。新功能在考虑中......
